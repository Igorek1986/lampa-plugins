🎨 Плагин «Стильный интерфейс» для Lampa/Lampac
Полностью переосмысленный главный экран: логотипы вместо названий, фоновые постеры, цветные рейтинги и гибкая настройка карточек.

🔹 Основные возможности:
- Логотип тайтла вместо текстового названия (с кешированием и плавной анимацией появления)
- Фон из постера/бэкдропа под карточкой, с выбором качества изображения (w300 / w780 / w1280 / оригинал)
- Панель информации: рейтинг TMDB, жанры, длительность, возрастное ограничение, статус (в эфире / завершён / онгоинг и др.)
- Опционально — количество сезонов и эпизодов
- Реакции пользователей CUB прямо на карточке
- Цветные рейтинги (от красного к салатовому в зависимости от оценки), с опциональной обводкой
- Широкие постеры как альтернативный стиль карточек
- Скрытие подписей (название/год) под карточками для более чистого вида
- Асинхронная фоновая подгрузка данных карточек — рейтинги и фон подсвечиваются без задержек при скролле
- Совместимость с источниками TMDB, CUB и NUMParser

⚙️ Технические особенности:
- Работает поверх стандартного главного экрана Lampa (Maker), не ломая остальной интерфейс
- Кеш логотипов и превью с ограничением по размеру — не растёт бесконечно при длительном скролле, старые записи вытесняются
- Кеш логотипов можно сбросить вручную через настройки
- Все элементы отображения включаются/выключаются независимо друг от друга
- Настройки доступны в разделе Настройки → Интерфейс → «Стильный интерфейс»
